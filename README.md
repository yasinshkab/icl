This project uses Next.js 16.3.2 (App Router), React 19 and Tailwind CSS v4. It supports Arabic (RTL) and English via `next-intl`.

## Quick start

Install and run the dev server:

```bash
npm install
npm run dev
```

Open http://localhost:3000 in your browser. Edit pages under the `app/` directory; changes hot-reload during development.

See `.env.example` for required environment variables (contact form delivery uses `SENDGRID_API_KEY` if provided).
